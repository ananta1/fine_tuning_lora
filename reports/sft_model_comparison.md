## SFT Observations
The SFT model demonstrates a massive leap in domain knowledge accuracy. It incorporates all custom code variables, database details, AWS dependencies, and formula heuristics. However, in some cases, SFT model outputs can feel slightly verbose and repetitive, mimicking the exact phrasing of the dataset templates. This will be aligned during the DPO stage.
